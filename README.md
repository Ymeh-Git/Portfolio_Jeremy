### Step 3 : Accessibility

Always think about <strong style="color:red">how your colors react with each others.</strong> It is really <strong style="color:red">important</strong> 

So I did, I used [WebAIM - contrast checker](https://webaim.org/resources/contrastchecker/)

Really usefull tool, I checked every combinaison. <br>
A few doesn't work : light/light, dark/dark. <br>
But most does work !
